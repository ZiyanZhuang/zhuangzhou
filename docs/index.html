From biological intent
to executable design. 从生物学意图
到可执行的设计。

Zhuangzhou is an AI Scientist Workbench for synthetic biology and enzyme engineering. It turns a stated intent — improve this enzyme, build this pathway, prepare this construct — into an auditable Design–Build–Test–Learn workflow. The AI proposes and coordinates; Zhuangzhou computes, checks, and records. 庄周是一个面向合成生物学与酶工程的 AI 科学家工作台。它把一句明确的意图 — 改良这个酶、构建这条通路、准备这个表达构件 — 转化为可审计的 设计–构建–测试–学习流程。AI 负责提议与协调,庄周负责计算、核验与记录。

The Problem问题所在

Design evidence, scattered
across incompatible layers. 设计证据,散落在
互不兼容的层级之间。

Synthetic biology projects often fail between the idea and the bench — not for lack of tools, but because no tool sees the whole loop. 合成生物学项目常常败在"想法"与"实验台"之间 — 不是缺少工具,而是没有一个工具能看到完整的闭环。

01

Pathway selection is separated from enzyme feasibility. 通路选择与酶的可行性评估相互脱节。

02

Enzyme mutations are proposed without structural or MD context. 酶突变的提出缺少结构或分子动力学层面的依据。

03

Expression cassettes are chosen without burden or host constraints. 表达元件的选择未考虑代谢负担与宿主约束。

04

Codon optimization runs without pathway-level design intent. 密码子优化脱离了通路层面的设计意图独立运行。

The AI proposes and coordinates. Zhuangzhou computes, checks, records, and packages — so scientific claims come from tools and data, not from unsupported text generation. AI 负责提议与协调,庄周负责计算、核验、记录与打包 — 让科学结论来自真实的工具与数据,而不是没有依据的文本生成。

The Workflow工作流程

One loop, run as executable steps. 一个循环,拆解为可执行的步骤。

Design–Build–Test–Learn is not a slide-deck framework here — each phase routes to real tools and returns inspectable evidence, and each cycle feeds the next. 设计–构建–测试–学习在这里不是一张概念图 — 每个阶段都对接真实工具、返回可核查的证据,每一轮循环又反哺下一轮。

Design设计
Decompose the biological goal; choose analyses; rank uncertainty across candidates. 拆解生物学目标,选择分析方法,对候选方案的不确定性排序。
pathway search · FBA/FVA · protein context · mutation enrichment · docking · MD · QM
Build构建
Translate designs into construct-level plans ready for a host chassis. 把设计转化为可交付宿主底盘的构件级方案。
promoter / RBS / Kozak selection · codon optimization · CRISPR guide design · integration strategy
Test测试
Prepare validation hypotheses and the measurable outputs that would confirm them. 准备验证假设,以及能够证实假设的可测量输出。
assay checklist · simulation metrics · report generation · result schema
Learn学习
Preserve what worked, what failed, and why — as evidence for the next round. 保留哪些方案成功、哪些失败及其原因 — 作为下一轮的证据。
project memory · execution history · knowledge context · next-round ranking
Learn feeds back into the next Design pass — the loop, not the phase, is the unit of progress. "学习"的结果会反馈到下一轮"设计" — 循环本身,而不是单个阶段,才是进展的度量单位。

Capabilities核心能力

Early-stage design support,
enzyme to pathway. 从单个酶到完整通路的
早期设计支持。

Pathway & Host Design通路与宿主设计
  • Genome-scale model bridge for E. coli and S. cerevisiae. 面向大肠杆菌与酿酒酵母的基因组尺度模型接口。
  • Flux balance analysis, flux variability analysis, gene essentiality, bottleneck search. 通量平衡分析、通量可变性分析、基因必需性判定、瓶颈搜索。
  • Pathway search connecting target products to feasible host interventions. 通路搜索,将目标产物与可行的宿主干预方案相连接。
  • Early chassis-level feasibility comparison before construct design. 在构件设计之前完成底盘层面的早期可行性比较。
Genetic Part Selection遗传元件选择
  • Curated promoter, RBS/Kozak, terminator, and integration-site libraries. 精选的启动子、RBS/Kozak 序列、终止子与整合位点库。
  • Assembor-style S. cerevisiae promoter/terminator table (name, type, bin, sequence, doi). Assembor 风格的酿酒酵母启动子/终止子表(name, type, bin, sequence, doi)。
  • Expression-strength matching for balanced pathway assembly. 表达强度匹配,用于平衡通路的整体组装。
  • Separate bacterial and yeast part logic where expression control differs. 在表达调控机制不同处,分别处理细菌与酵母的元件逻辑。
CRISPR & PerturbationCRISPR 与扰动
  • SpCas9 guide search with NGG PAM handling. 支持 NGG PAM 识别的 SpCas9 引导序列搜索。
  • Knockout and CRISPRi-oriented design helpers. 面向基因敲除与 CRISPRi 的设计辅助工具。
  • HDR template design utilities for edit planning. 用于编辑方案规划的 HDR 模板设计工具。
Codon Optimization密码子优化
  • Komagataella phaffii-oriented optimization engine. 面向毕赤酵母的优化引擎。
  • DNAchisel backend when installed, with a frequency-based fallback. 安装 DNAchisel 时作为后端调用,否则回退到基于密码子频率的方案。
  • GC-content constraints, translation enforcement, avoid-pattern hooks. GC 含量约束、翻译一致性校验、序列规避模式钩子。
Genomics Computation基因组学计算
  • VCF and population-map input-contract checks before analysis. 分析前对 VCF 与群体分组文件进行输入契约检查。
  • Auditable command plans: diversity, Tajima’s D, Fst, PCA, ADMIXTURE, TreeMix, IQ-TREE. 可审计的命令方案:多样性、Tajima's D、Fst、PCA、ADMIXTURE、TreeMix、IQ-TREE。
  • Explicit QC defaults for MAF, missingness, LD pruning, and runtime capture. 对 MAF、缺失率、连锁不平衡剪除等设有明确质控默认值,并记录运行过程。
Enzyme Engineering酶工程
  • Mutation enrichment: secondary structure, RSA, active-site distance, channel proximity, literature evidence. 突变富集分析:二级结构、相对溶剂可及性、活性位点距离、通道邻近性、文献证据。
  • Docking, MD, and QM for ranking mutations beyond sequence-only heuristics. 结合对接、分子动力学与量子化学计算,超越单纯序列层面的启发式排序。
  • CYP/heme-aware Amber and GROMACS support for metalloprotein engineering. 面向金属蛋白工程,支持感知 CYP/血红素结构的 Amber 与 GROMACS 流程。
  • Integrated CYPForge helpers for heme + ligand Amber preparation and run-readiness gates. 集成 CYPForge 辅助工具,用于血红素+配体的 Amber 前处理与运行就绪检查。
Technical Notes技术说明
Tool-grounded, not text-only依托真实工具,而非纯文本生成
The LLM plans and coordinates; outputs are computed by Python modules, database APIs, and simulation engines. 大模型负责规划与协调;实际输出由 Python 模块、数据库接口与仿真引擎计算得出。
Pluggable model layer可插拔的模型层
Claude, OpenAI-compatible APIs, DeepSeek-compatible endpoints, and local Ollama backends are optional planners. Claude、OpenAI 兼容接口、DeepSeek 兼容端点、本地 Ollama 后端均可作为可选的规划模型。
Environment isolation环境隔离
Native tools, WSL tools, conda environments, and remote SSH compute configure independently. 本机工具、WSL 工具、conda 环境与远程 SSH 计算资源可独立配置。
Privacy-conscious by default默认注重隐私
API keys, host paths, SSH settings, and heavyweight model files stay externalized and git-ignored. API 密钥、主机路径、SSH 配置与大体积模型文件均外部化存放,并被 git 忽略。
Reproducible packaging可复现的打包方式
Source distributions exclude caches, logs, credentials, storage exports, and large checkpoints. 源码分发包排除缓存、日志、凭证、存储导出文件与大体积检查点。
Structured reporting结构化报告
Design outputs convert into Word-style reports and reusable project-memory records. 设计输出可转换为 Word 风格报告以及可复用的项目记忆记录。
Get Started快速开始

Requires Python 3.10 or newer. 需要 Python 3.10 及以上版本。

Install安装
git clone https://github.com/ZiyanZhuang/zhuangzhou.git cd zhuangzhou python -m pip install -e .
Optional feature groups可选功能组
pip install -e ".[nlp]" pip install -e ".[chem]" pip install -e ".[codon]" pip install -e ".[viz]" pip install -e ".[all]"
Talk to it对话式使用
zz-chat > Improve production of a target compound in yeast. > Compare pathway options, identify likely enzyme bottlenecks, > propose expression parts, and prepare a DBTL design package.
zz-chat > 提高某目标化合物在酵母中的产量。 > 比较通路方案,找出可能的酶瓶颈, > 提议表达元件,并准备一份 DBTL 设计方案。
Or call it directly或直接调用
from zhuangzhou.synbio.parts import PartSelector parts = PartSelector.select_promoter( organism="ecoli", strength=0.6, inducible=False, n_candidates=3, ) # -> ranked promoter candidates with expression-strength metadata# -> 返回带表达强度元数据的启动子候选排序
